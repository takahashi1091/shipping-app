# 出荷支援アプリ（MVP）

iPhone（Safari / ホーム画面追加）向けの出荷業務支援アプリです。  
**サーバーは使いません。** 店舗マスタ・出荷履歴・設定はすべて端末の IndexedDB に保存します。

## できること（今回の範囲）

- 出荷処理（バーコード読取 → 店舗検索 → 標準運送会社表示 → サイズ選択 → 必要なら運送会社変更 → 登録）
- 当日同じ店舗が既にあるときは確認ダイアログ（小口追加 / 別口として追加 / キャンセル）
- 店舗マスタの追加・編集・削除（郵便番号・住所は任意）
- CSV インポート / エクスポート（カンマ区切り。店舗コードは 6 桁ゼロ埋め）
- 出荷履歴の一覧・絞り込み・CSV / Excel 出力
- カメラ読取（Code128 / EAN / QR など）
- PWA（ホーム画面に追加、オフライン用キャッシュ）
- ダークモード（設定、または端末の外観に合わせる）

今回は入れていません（後から足しやすい構造にしてあります）。

- サイズによる運送会社の自動切替
- 店舗ごとの複雑な特別配送ルール
- 運送会社別・日別・月別の集計画面（集計関数は `js/reports.js`）
- 送り状番号の入力
- バックアップ JSON・ラベル印刷

## ファイル構成

```
shipping-app/
  index.html              … 画面（1ファイルで全メニュー）
  css/style.css           … スマホ向けの見た目
  js/constants.js         … サイズ・運送会社などの定数
  js/db.js                … IndexedDB
  js/rules.js             … 運送会社の決め方（将来の自動切替用）
  js/reports.js           … 件数集計の土台（画面はまだ出さない）
  js/csv.js               … CSV / Excel の読み書き
  js/scanner.js           … カメラバーコード
  js/app.js               … 画面操作のつなぎ込み
  sw.js                   … オフライン用サービスワーカー
  manifest.webmanifest    … PWA 設定
  icons/                  … ホーム画面アイコン
  sample-stores.csv       … 取込サンプル
```

JavaScript は機能ごとに分けています。コメントは日本語です。

## iPhone での使い方

カメラと PWA（ホーム画面追加・オフライン）は **HTTPS** が必要です。  
PC のフォルダをそのまま `file://` で開く、社内の `http://192.168.x.x` ではカメラが動かないことがあります。

例:

1. このフォルダを GitHub Pages など HTTPS で公開する（データは各 iPhone 内。公開されるのはアプリのファイルだけ）
2. Safari でその URL を開く
3. 共有 → **ホーム画面に追加**
4. メニュー「CSVインポート」から `sample-stores.csv` または自社 CSV を取り込む
5. 「出荷処理」でバーコードを読む

カメラが使えないときは、店舗コードを手入力して「検索」できます。

## CSV の列

店舗マスタ（カンマ区切り）:

```
店舗コード,店舗名,標準運送会社,特別条件,郵便番号,住所,備考
001001,東京店,佐川,,100-0001,東京都千代田区,
```

出荷履歴:

```
日付,店舗コード,店舗名,運送会社,サイズ区分,登録区分,備考,日時,送り状番号
```

- 書き出しは UTF-8（BOM 付き）のカンマ区切りです
- 取込時、数字の店舗コードが 6 桁未満なら先頭に `0` を付けます（123 → 000123）
- Excel の日本語 CSV（Shift_JIS）も UTF-8 も自動判別します
- インポートは「店舗コード単位で上書き追加」または「全件入れ替え」

運送会社の例: ヤマト / 佐川 / 西濃 / 福山 / その他  
サイズの例: 小口 / 中型 / 大型 / ワンピースロッド  
値の増減は `js/constants.js` を編集します。

## 特別条件について

マスタの「特別条件」は出荷画面に警告として表示します。  
MVP では運送会社の自動切替はせず、担当者が必要なら運送会社を手動変更します。

## データの場所

この iPhone のブラウザ（またはホーム画面アプリ）専用です。  
機種変更や Safari のデータ削除で消えます。定期的に CSV エクスポートしてください。

## ローカル PC での確認

HTTPS なしでも、店舗検索・CSV・履歴は確認できます（カメラは制限されることが多いです）。

フォルダを VS Code / Cursor の Live Preview や、任意の静的ファイル公開で開いてください。
